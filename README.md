BookDash Skills Lab – Sample Data README
LiveBooks™ System – Practice File Set

This sample data is provided as part of the BookDash Skills Lab and the LiveBooks™ System. These files are designed exclusively for hands-on practice inside a QuickBooks Online test company or sandbox environment. The datasets intentionally include inconsistencies, irregularities, and variations to reflect the kinds of issues commonly found in real client files. This is a practice environment, and you are encouraged to explore, test, and problem-solve without concern for making mistakes.

To ensure a smooth import process, follow the steps below in the exact order provided.

Recommended Import Order:

1) Chart of Accounts
2) Products & Services
3) Customers
4) Vendors
5) Invoices
6) Credit Card Transactions
7) Bank Transactions

Before importing, create a clean test company or reset your existing test file. Do not combine these datasets with other practice files.

These files are intended to help you build confidence and develop real-world judgment by reviewing, cleaning, and interpreting realistic bookkeeping data.
